# 宠物图像分割：U-Net 复现与轻量化

图像处理课程项目。使用 Oxford-IIIT Pet 数据集进行宠物前景分割，复现标准 U-Net，并将部分普通卷积替换为深度可分离卷积，比较模型大小、分割质量和 CPU 推理速度。

## 实验结果

两种模型使用相同的数据划分和训练设置，在 3,669 张测试图像上评估分割质量。

| 模型 | 前景 IoU | 前景 Dice | 参数量 | 单图 CPU 推理中位耗时 |
| --- | ---: | ---: | ---: | ---: |
| 标准 U-Net | 71.59% | 83.44% | 31,037,698 | 131.85 ms |
| 轻量 U-Net | 77.48% | 87.31% | 6,216,898 | 49.92 ms |

计时使用同一张预加载的 128×128 图像，CPU 6 线程，每个模型预热 5 次、测量 30 次。耗时仅包含模型前向计算。
